# لعبة الهروب من السجن — حزمة التطبيق

هذه الحزمة تحوّل اللعبة إلى تطبيق ويب قابل للتثبيت (PWA) على iPhone وAndroid.

## الملفات
- `index.html`: اللعبة الأصلية مع بيانات التثبيت والتسجيل دون تغيير أسئلة اللعبة أو منطقها.
- `manifest.json`: اسم التطبيق وأيقوناته وطريقة عرضه.
- `service-worker.js`: تخزين ملفات التطبيق للتشغيل دون إنترنت بعد أول زيارة ناجحة.
- `icons/`: أيقونات التطبيق.

## النشر
يجب رفع **كل محتويات هذا المجلد** إلى استضافة تدعم HTTPS. يمكن استخدام GitHub Pages:
1. أنشئ مستودع GitHub جديداً.
2. ارفع `index.html` و`manifest.json` و`service-worker.js` ومجلد `icons`.
3. من Settings ثم Pages اختر النشر من الفرع الرئيسي (main) ومجلد الجذر (root).
4. افتح رابط الموقع الناتج باستخدام HTTPS وانتظر تحميل اللعبة مرة واحدة مع الإنترنت.

## التثبيت
- iPhone: افتح الرابط في Safari، ثم Share، ثم Add to Home Screen.
- Android: افتح الرابط في Chrome، ثم القائمة، ثم Install app أو Add to Home screen.

## ملاحظات
- لا يمكن تثبيت PWA من ملف HTML محلي مباشرة؛ يلزم رابط HTTPS.
- العمل دون إنترنت يتوفر بعد فتح الموقع أول مرة بنجاح وتنزيل ملفات التخزين.
- هذه الحزمة لم تُنشر على الإنترنت ولم يتم اختبار تثبيتها على أجهزة فعلية.
